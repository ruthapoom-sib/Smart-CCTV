# CCTV Wall Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** หน้าเว็บ static หน้าเดียวที่เล่นภาพสดกล้องจราจรฉะเชิงเทรา 40 จุดเป็น grid พร้อมโหมดวนหน้าอัตโนมัติแบบ VMS และ deploy บน Vercel ได้โดยไม่ต้อง build

**Architecture:** ทุกอย่างอยู่ใน `index.html` ไฟล์เดียว (HTML + CSS + JS แบบ classic script)
- script แบ่งเป็น section ตามลำดับ: `data` → `logic` → `player` → `ui` → `tour` → `start` → `self-check`
- แต่ละ task จะ **เพิ่ม section ใหม่ไว้ก่อนบรรทัด `// ── start ──`** หรือแก้ฟังก์ชันที่ระบุชื่อไว้
- หน้าแสดงเฉพาะกล้องในหน้าปัจจุบัน และทำลายตัวเล่นทั้งหมดเมื่อเปลี่ยนหน้า

**Tech Stack:** HTML/CSS/vanilla JS, hls.js 1.7.3 (jsDelivr), Google Fonts Anuphan ตรวจด้วย `python -m http.server` + Playwright MCP

**Spec:** `docs/superpowers/specs/2026-09-27-cctv-wall-design.md`

## Global Constraints

- ไฟล์ของแอปมีแค่ `index.html` ที่ root ของ repo ไม่มี build และไม่มี `package.json` หรือ `vercel.json`
- สตรีม: `https://camerai1.iticfoundation.org/hls/ccs${id}.m3u8`
- hls.js pin เวอร์ชัน `1.7.3` จาก `https://cdn.jsdelivr.net/npm/hls.js@1.7.3/dist/hls.min.js`
- ข้อความในหน้าเป็นภาษาไทย ไม่ใช้ป้ายตัวพิมพ์ใหญ่ทั้งหมด และไม่ใช้ `·` คั่นข้อความ
- layout: 2, 3, 4 (แสดงบนปุ่มเป็น "4 จอ", "9 จอ", "16 จอ") ค่าเริ่มต้นคือ 3
- ความถี่: 10 / 15 / 30 / 60 วินาที ค่าเริ่มต้นคือ 15
- Auto เปิดเป็นค่าเริ่มต้น และค่าเริ่มต้นของทางแยกคือทุกทางแยก (`g = -1`)
- key ใน localStorage คือ `cctv` เก็บค่า `{ n, interval, auto, g }`
- สี: asphalt `#1F2327`, kerb `#343A40`, sign `#0A6B47`, paint `#F6F6F1`, lane `#F2B705`, stop `#E5484D`, go `#2FBF71`, dim `#9BA4AC`
- ลองต่อใหม่: network error สร้างตัวเล่นใหม่หลัง 3 s สูงสุด 3 ครั้ง ต่อจากนั้นถือว่าออฟไลน์และลองใหม่ทุก 30 s
- ตรวจสถานะทุกกล้องทุก 60 s

## Review Focus

1. **ทางแยกที่มีหน้าเดียว** (เช่น 3 กล้องใน 9 จอ) ขณะ Auto เปิด: ต้องไม่ render ใหม่ทุกรอบ ภาพต้องไม่กระตุกเริ่มใหม่ (Task 4)

```js
// ── logic ──
const chunk = (list, size) => {
  const out = [];
  for (let i = 0; i < list.length; i += size) out.push(list.slice(i, i + size));
  return out;
};
const wrap = (i, len) => ((i % len) + len) % len;
const uniqueById = list => list.filter((c, i) => list.findIndex(d => d.id === c.id) === i); // ponytail: O(n²) พอสำหรับ 42 แถว ถ้ากล้องมีเป็นหลักพันให้เปลี่ยนไปใช้ Set ของ id
const camsFor = g => (g < 0 ? uniqueById(CAMS) : CAMS.filter(c => c.g === g));
```

```js
// ── player ──
const MSG = { connecting: 'กำลังเชื่อมต่อ…', live: '', offline: 'ไม่มีสัญญาณ จะลองเชื่อมต่อใหม่อัตโนมัติ', unsupported: 'เบราว์เซอร์นี้เล่นวิดีโอสดไม่ได้' };

function play(tile, cam) {
  const video = tile.querySelector('video');
  let hls = null, fails = 0, timer;
  video.muted = true; // autoplay ต้อง muted; ตั้ง property ด้วยเพราะ clone จาก template อาจไม่ได้ค่านี้มา
  const set = s => { tile.dataset.state = s; tile.querySelector('.msg').textContent = MSG[s]; };
  const stop = () => {
    clearTimeout(timer);
    hls?.destroy();
    hls = null;
    video.onerror = null;
    video.removeAttribute('src');
    video.load();
  };
  const retry = ms => { stop(); timer = setTimeout(start, ms); };
  const offline = () => { set('offline'); retry(30_000); };

  function start() {
    set('connecting');
    if (window.Hls?.isSupported()) {
      let recovered = false;
      hls = new Hls({ backBufferLength: 30 }); // จำกัด buffer ย้อนหลัง เพราะจอ wall เปิดทิ้งไว้ทั้งวัน
      hls.on(Hls.Events.MANIFEST_PARSED, () => video.play().catch(() => {}));
      hls.on(Hls.Events.ERROR, (_, d) => {
        if (!d.fatal) return;
        if (d.type === Hls.ErrorTypes.MEDIA_ERROR && !recovered) { recovered = true; hls.recoverMediaError(); }
        else if (d.type === Hls.ErrorTypes.NETWORK_ERROR && ++fails < 3) retry(3000);
        else offline();
      });
      hls.loadSource(SRC(cam.id));
      hls.attachMedia(video);
    } else if (video.canPlayType('application/vnd.apple.mpegurl')) { // iOS Safari
      video.onerror = offline;
      video.src = SRC(cam.id);
    } else {
      set('unsupported');
    }
  }

  video.onplaying = () => { fails = 0; set('live'); };
  start();
  return stop;
}
```
