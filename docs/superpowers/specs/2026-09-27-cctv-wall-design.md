# CCS Smart City CCTV Wall — Design

วันที่: 2026-09-27

## เป้าหมาย

รวมกล้อง CCTV ทุกตัวของ Chachoengsao Smart City (ที่มา: https://sites.google.com/view/ccs-cctv) มาแสดงในหน้าเว็บเดียว หน้าตาเรียบง่ายและสวย
ทำงานแบบโปรแกรมดูกล้อง (VMS) มีโหมด Auto tour วนหน้าในจอเดียว และเปิดดูออนไลน์ได้

**สำเร็จเมื่อ:**
- เปิด URL แล้ววิดีโอเล่นเองทันทีโดยไม่ต้องกดอะไร
- tour วนครบทุกกล้อง
- กล้องที่ล่มแสดงสถานะชัดเจนและไม่ทำให้หน้าค้าง
- deploy บน Vercel ได้โดยไม่ต้อง build

## สถาปัตยกรรม

- ใช้ไฟล์ static เดียวคือ `index.html` ที่ root ของ repo รวม HTML, CSS และ JS ไว้ด้วยกัน ไม่มีขั้นตอน build
- dependency ตัวเดียวคือ **hls.js** โหลดจาก jsDelivr และ pin เวอร์ชัน 1.x ล่าสุด ณ วันที่ implement
- ฟอนต์ใช้ Anuphan (ฟอนต์ไทยไม่มีหัว อ่านง่ายแบบป้าย) จาก Google Fonts
- รายชื่อกล้องเก็บเป็น array ใน `index.html` ในรูป `{ id, group, name }`
  - ในมุมมอง "ทุกจุด" จะตัดตัวซ้ำด้วย `id` ให้เหลือ 40 ตัว
  - เมื่อกรองตามทางแยก จะแสดงครบทุกตัวในกลุ่มนั้น รวมตัวที่ซ้ำด้วย
- Deploy: import repo `ruthapoom-sib/Smart-CCTV` เข้า Vercel team `ruthapoom`
  - เลือก Framework = Other และเว้น Build Command ว่าง
  - ไม่ต้องมี `vercel.json`
  - push ขึ้น `main` แล้วจะ deploy ให้อัตโนมัติ

## UI

ธีมมืดแบบห้องควบคุม (control room) เต็มจอ บนเดสก์ท็อปไม่มี scroll

**ภาษาภาพ "ป้ายจราจรไทย":**
- จุดเด่นมีจุดเดียว คือป้ายชื่อบน tile ที่ทำเหมือนป้ายบอกทางสีเขียว มีเส้นขอบขาวด้านใน
- ส่วนอื่นเรียบๆ บนพื้นสีถนนยางมะตอย
- progress bar ทำเป็นเส้นประแบ่งช่องจราจรสีเหลือง
- สีหลัก: asphalt `#1F2327`, kerb `#343A40`, sign green `#0A6B47`, paint `#F6F6F1`, lane amber `#F2B705`, stop red `#E5484D`, go green `#2FBF71`

- **Header:** มีองค์ประกอบดังนี้
  - ชื่อ "กล้องจราจรฉะเชิงเทรา" และคำอธิบาย "ภาพสด 40 จุด ในเขตเทศบาลเมืองฉะเชิงเทรา"
  - ตัวนับ `● LIVE n/40` นับจากการ `fetch` playlist `.m3u8` ของทุกกล้องทุก 60 s (ไฟล์ละ 138 bytes) ได้ 200 ถือว่าออนไลน์
  - นาฬิกา
  - ปุ่ม layout 2x2 / 3x3 / 4x4
  - ปุ่ม ▶/⏸ Auto และตัวเลือกความถี่ 10 / 15 / 30 / 60 วินาที
  - ปุ่ม ← → เปลี่ยนหน้า
  - dropdown เลือกทางแยก ("ทุกจุด" + 10 ทางแยก)
  - ปุ่มเต็มจอ
- **Grid:** ขนาด N×N เต็มพื้นที่ที่เหลือ tile มีอัตราส่วน 16:9
  - หน้าสุดท้ายที่มีกล้องไม่เต็ม ช่องที่เหลือปล่อยว่างไว้
- **Tile:** แต่ละช่องประกอบด้วย
  - `<video muted autoplay playsinline>`
  - ป้ายซ้อนมุมล่าง แสดงรหัส ccsNN, ชื่อจุด และชื่อทางแยก
  - จุดสถานะ: live (เขียว), กำลังเชื่อมต่อ (เหลือง กระพริบ), ออฟไลน์ (แดง พร้อมข้อความ "ออฟไลน์")
- **Footer:** แสดง "หน้า x/y" และ progress bar นับถอยหลังก่อนเปลี่ยนหน้า
- **ขยายกล้อง:** คลิก tile เพื่อขยายเต็มพื้นที่ grid แล้วหยุด tour ชั่วคราว
  - คลิกอีกครั้งหรือกด Esc เพื่อกลับ และ tour เดินต่อ
- **คีย์ลัด:** Space = Auto on/off, ← → = เปลี่ยนหน้า, F = เต็มจอ, Esc = ยกเลิกการขยาย
- **Responsive:** จอแคบกว่า 700px ให้ grid เป็น 1 คอลัมน์ scroll แนวตั้งได้ และ header ย่อเป็นสองแถว
- บันทึก layout, ความถี่, สถานะ Auto และทางแยกที่เลือกไว้ใน `localStorage`

## Tour และการจัดการทรัพยากร

- `pages = chunk(filteredCameras, n*n)` และ `next = (page + 1) % pages.length`
- เลื่อนหน้าทุก `interval` วินาทีเมื่อ Auto เปิดอยู่และไม่ได้ขยายกล้องค้างไว้
  - กดเปลี่ยนหน้าเองจะรีเซ็ตตัวนับถอยหลัง
- สร้างตัวเล่น hls.js เฉพาะกล้องที่อยู่ในหน้าปัจจุบัน
  - ก่อนเปลี่ยนหน้า เรียก `hls.destroy()` และล้าง `video.src` ของทุก tile เดิม
  - แบนด์วิดท์จึงไม่เกินจำนวนช่องบนจอ (3x3 ≈ 4 Mbps)
- ถ้า `Hls.isSupported()` เป็นเท็จ แต่ `video.canPlayType('application/vnd.apple.mpegurl')` ใช้ได้ (เช่น iOS Safari) ให้เล่นด้วย HLS ในตัวเบราว์เซอร์

## Error handling

- fatal `NETWORK_ERROR`: สร้างตัวเล่นใหม่หลัง 3 s เพราะ `startLoad()` ไม่โหลด manifest ใหม่หลังเกิด manifest error ถ้าล้มเหลวติดกัน 3 ครั้ง ให้ถือว่าออฟไลน์
- fatal `MEDIA_ERROR`: เรียก `hls.recoverMediaError()` 1 ครั้ง ถ้ายังไม่หายให้ถือว่าออฟไลน์
- เมื่อออฟไลน์: `destroy()` ตัวเล่น แสดง tile ออฟไลน์ แล้วลองเชื่อมต่อใหม่ทุก 30 s ตราบที่ tile นั้นยังอยู่บนจอ
- native HLS (Safari): เมื่อเกิด `error` event ให้ถือว่าออฟไลน์ และลองใหม่ทุก 30 s เหมือนกัน

## Testing

- **Self-check:** เปิด `index.html#test` เพื่อรัน `console.assert` ตรวจ logic
  - `chunk` แบ่งหน้าถูกต้อง
  - หน้าสุดท้ายวนกลับหน้าแรก
  - มุมมอง "ทุกจุด" ตัดตัวซ้ำเหลือ 40 ตัว
  - แสดงผลลัพธ์ผ่าน/ไม่ผ่านบนหน้าจอ
- **ตรวจบนเบราว์เซอร์จริง (Playwright):**
  - วิดีโอในหน้าแรกเล่นได้ (`currentTime` เพิ่มขึ้น)
  - Auto เลื่อนหน้าเองเมื่อครบเวลา
  - `ccs42` แสดงเป็นออฟไลน์
  - เปลี่ยน layout ได้
  - คลิกขยายและ Esc ทำงาน
  - console ไม่มี error ที่ไม่ได้คาดไว้

## ไม่รวมในงานนี้

- แผนที่: เว็บต้นทางมีหน้าแผนที่อยู่แล้ว
- ดูภาพย้อนหลัง: ต้องติดต่อเทศบาล และไม่มีสตรีมให้ใช้
- preload หน้าถัดไป: เพิ่มเมื่อช่วงรอโหลด 1-3 s ตอนเปลี่ยนหน้ารบกวนการใช้งาน
- ระบบ login และการตั้งค่าผ่าน URL parameter
